# v1.0.0 arithmetic and invariant review

Reviewed on October 17, 2026. Supported Node runtimes start at 22; verification
runs on Node 22 and 24. This records the scope of the review, not a guarantee
about subsequent changes. Run `npm run verify` again for the final release commit.

## How coverage is measured

`npm run test:coverage` runs Vitest with V8 execution coverage. Coverage is mapped
back to TypeScript and includes executable code under `src/**/*.ts`; only the
type-only `src/types.ts` file is excluded. Reports are written to
`coverage/index.html` and `coverage/coverage-summary.json`.

- **Lines:** executable lines reached by tests.
- **Statements:** individual statements reached, including multiple statements on a line.
- **Functions:** functions invoked at least once.
- **Branches:** alternatives taken through conditionals and other branching expressions.

Coverage measures execution, not correctness. A wrong formula can have 100% line
coverage. Confidence also requires independently calculated expected values,
invariants over generated inputs, error cases, and checks of the installed
package. Ratio comparisons allow tiny floating-point differences; integer
monetary amounts are compared exactly. Existing determinism snapshots remain
unchanged.

The enforced global thresholds are 95% statements, 95% lines, 90% branches, and
100% functions. The review measured 99.37% statements, 100% lines, 95.1% branches,
and 100% functions. Unvisited branches are still visible in the HTML report.

## Hand-calculated forecast

Commitment is 10,000 minor units ($100 when units are cents), starting January
15, 2024. Use four annual periods, 10% annual growth, commitment call weights
`[0.4, 0.3, 0.2, 0.1]`, explicit NAV distribution rates `[0, 0.25, 0.5, 1]`, and
terminal liquidation enabled. Distribution rates apply to grown prior NAV,
excluding the current call.

All amounts in this table are dollars:

| Period end | Call | Distribution | Closing NAV | Cumulative calls | Cumulative distributions | Unfunded | Net cash flow |
|---|---:|---:|---:|---:|---:|---:|---:|
| 2024-12-31 | 40.00 | 0.00 | 40.00 | 40.00 | 0.00 | 60.00 | -40.00 |
| 2025-12-31 | 30.00 | 11.00 | 63.00 | 70.00 | 11.00 | 30.00 | -19.00 |
| 2026-12-31 | 20.00 | 34.65 | 54.65 | 90.00 | 45.65 | 10.00 | 14.65 |
| 2027-12-31 | 10.00 | 70.12 | 0.00 | 100.00 | 115.77 | 0.00 | 60.12 |

For example, year two starts with $40, grows to $44, distributes 25% of $44
($11), and receives a $30 call: closing NAV is $63. In the final year,
`$54.65 * 1.1 = $60.115`, rounded to $60.12. Liquidation distributes that amount
plus the final $10 call. Final DPI and TVPI are 1.1577 and RVPI is zero.

With liquidation disabled, the final distribution is $60.12 and NAV is $10;
TVPI is still 1.1577. Fractional curves do not round to cents: their final
distributed fraction is 1.15765. This explains the small difference between the
curve and the rounded monetary projection.

These full rows and ratios are retained in `tests/hand-calculated.test.ts` as
explicit expectations. Expected monetary values are not generated by engine
helpers or snapshot updates.

## Hand-calculated history and rescaling

Use a one-year quarterly fund, zero growth, four 25% commitment calls, explicit
zero distributions, and no liquidation. Supplied history includes $30 of calls
in period 0 (including a pre-start call), $1 of distributions, a selected $29 NAV,
then a $36 NAV in period 1. Older NAV observations and equal-date ties exercise
the documented selection rules. Missing period-1 calls and distributions are zero.

| Period end | Source | Call | Distribution | NAV | Unfunded |
|---|---|---:|---:|---:|---:|
| 2024-03-31 | actual | 30.00 | 1.00 | 29.00 | 70.00 |
| 2024-06-30 | actual | 0.00 | 0.00 | 36.00 | 70.00 |
| 2024-09-30 | forecast | 35.00 | 0.00 | 71.00 | 35.00 |
| 2024-12-31 | forecast | 35.00 | 0.00 | 106.00 | 0.00 |

Remaining calls split the $70 remaining commitment over the two equal original
forecast amounts. The call deltas against baseline are `$5, -$25, $10, $10`;
NAV deltas are `$4, -$14, -$4, $6`. `asOf` is June 30, 2024.

The retained examples also check all eight combinations of supplied/missing
calls, distributions, and NAV within the actual horizon; reported zero NAV;
overcalling; unfunded-basis calls; distribution caps; terminal liquidation;
annual-to-quarterly conversion; and extension beyond the baseline horizon.

## Independent arithmetic comparison

A separate review used Python's exact `Fraction` arithmetic and integer
half-up rounding for nonnegative amounts. It did not import library code or
test helpers. It calculated expected complete rows for 360 distinct scenarios:

- Commitments of 3, 7, 10,000, 10,001, and 999,999 minor units.
- Annual, semiannual, and quarterly periods.
- Per-period growth of 0%, 25%, and -50%, entered as equivalent annual rates.
- Both call bases, both distribution bases, and liquidation on/off.

All complete rows matched the built public library under Node 22 and 24 in UTC,
America/Los_Angeles, and Pacific/Kiritimati: 2,160 scenario executions and 120,960
field comparisons. Monetary and calendar fields were exact; ratios used
`1e-14` relative/absolute tolerance. Each run also checked empty-actual equivalence,
zero variance, conservation, nonnegative NAV, and finite outputs.

## Mapping to the nine invariants

| Invariant | Review evidence |
|---|---|
| 1. Exact commitment calls | Hand-calculated totals; independent exact-fraction scenarios; tiny/near-100% allocation regression properties. |
| 2. Scale/calendar-independent curves | Explicit fractional expectations; unchanged curves after different investment sizes and dates. |
| 3. Empty actuals is a no-op | Full row comparison and zero variance in the hand example and independent scenarios. |
| 4. Conservation | Calls plus unfunded equal commitment; net cash equals distributions minus calls, including overcalling. |
| 5. Nonnegative NAV | Hand examples, independent positive/negative-growth scenarios, caps, and generated histories. |
| 6. Preserve supplied history | Explicit aggregate values, pre-start calls, latest-date/tied NAV observations, zero NAV, and all missing-input combinations. |
| 7. Determinism | Node 22/24 and three timezones; existing shared Node/jsdom snapshots. |
| 8. Derived term and period mapping | Explicit annual/quarterly dates and row counts; independent three-frequency scenarios; invalid-term regression tests. |
| 9. Rescaling after actuals | Explicit $35/$35 remaining calls; overcall exception; existing generated rescaling properties. |

The full verification also checks malformed inputs, unsafe arithmetic, semantic
date errors, executable docs, package contents, isolated ESM/CJS installs,
optional schemas, strict consumer types, and browser-target bundling. Browser
bundling and jsdom do not replace real browser-engine testing.
